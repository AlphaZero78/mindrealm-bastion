# 操作音效、战场清晰度与自然地形

2026-09-05。本次按用户的三项体验反馈更新 Web 版，不修改原计划副本。

## 实际变化

- 点击从长电脑噪声改为65毫秒短音，部署为180毫秒。复用已有授权素材的短片段，单独低通、淡入淡出；选择/取消45毫秒。同一次部署只调用部署音，UI单声部替换，过期加载不补播。
- 战场按CSS实际尺寸绘制，设备像素倍率最多1.5；像素图集独立使用最近邻。地形线条、中文和标记不再跟着整块低分辨率画布放大。
- 左侧信息与单位操作、右侧战场、底部费用与合法提示各有独立区域。部署卡片不再附带浏览器默认的整卡拖拽影像；确认窗与提示消息留在信息栏内。
- 射程填色区、实际可攻击的实线边界、视线遮挡的虚线区域使用战斗同一判定。范围边界和拖拽构造最后绘制，入口/火种短标签自动避让实体。原生拖拽事件立即更新画面，避免浏览器暂停动画帧时没有射程。
- 新局由随机山脊、平台和弯曲谷道构成，四入口始终有零高度通路到火种。保留41×41、0–4高度、保护区，初始相邻高差不超过1。旧局保存的地形原样载入；需要开始新远征才能看到新的地形生成。

## 规则边界

用户本次反馈覆盖此前低分辨率显示和固定方形高台的技术选择。提高画布清晰度不改变20Hz战斗步进、视线或伤害；新地形改变部署位置与通道策略，不改变开局资源、路线、奖励与节点规则。生成算法不使用奖励随机流，不重写已有存档。
