# 分辨率与界面转场验收

2026-09-05，当前 Web 版。原计划副本保留，本次补充显示选项与界面过渡。

## 玩家可用内容

- 设置提供自动适配、960×540、1280×720、1600×900、1920×1080、2560×1440画面渲染分辨率。即时生效、自动保存；保存失败时保留原选择。固定档位按窗口比例适配，中文DOM界面独立保持清晰。
- 菜单、设置、帮助、图鉴、路线、节点、战前、战斗、奖励和结算使用240ms交叉淡化；弹窗180ms淡入、120ms淡出。操作确认与存档同步提交，战斗计时等待过渡结束。
- 动画期间阻止重复操作与点击穿透。取消弹窗后恢复键盘焦点，切换窗口尺寸或隐藏页面会立即清理动画；“减少动态效果”和系统减少动态偏好可关闭转场。
- 保留快照的隐藏教学与部署布局状态，先定位新战场镜头再绘制首帧。修复验收中发现的旧突破历史显示NaN问题，结算与日志统一显示时间及突破敌人。

## 验证结果

- 最终构建运行118项源码测试，全通过。包括设置迁移与存储中断、各档位绘制/拾取、转场异常降级与清理、弹窗快速重开/取消/键盘焦点，以及混合历史显示回归。
- `browser-display-transitions.js`在源码及便携版均通过38项真实浏览器检查：六档画布尺寸、真实刷新持久化、保存失败回退、五窗口×三档UI缩放、低分辨率实际鼠标部署、首帧镜头、关闭焦点、系统减少动态、连续切换、resize清理及战斗开始计时。已实际查看各尺寸设置、部署画面和转场中间帧。
- 独立浏览器主流程19项、节点服务18项通过。真实界面完成三幕48节点、20战、3首领并胜利：618击杀、0突破、精神155/155、181碎片。部署用合法参考策略，战斗通过QA按实际规则步进加速，并非人工实时通关。
- 空阵在第二场战斗失败，27突破、111突破伤害，成功进入失败结算。将该实际失败状态保存在隔离临时文件，刷新后重载检查结算与日志，均无NaN/undefined。胜负终态均无残留动画、输入锁、脚本、渲染、音频或资源错误。
- 资源核验：73项必需文件、107项资产哈希、7份许可证通过。发布CMD/Windows PowerShell入口在隔离4186端口实际启动；89项发布清单哈希、16个Web源码逐一一致。
