# 《心域防线》Web 版玩法规则

玩家扮演能调整精神频率的“偏频者”，在三幕路线中收集心智构造、调整地形并守护醒觉火种。胜利需要完成最终首领战；失败后可从突破、死亡压力、构造损毁和带宽过载等记录复盘防线。

本说明对应当前 Web 实现。它保留两份计划确定的三幕流程、41×41 微网格、斜坡与可破坏峭壁、八方向像素单位和自适应音乐，替代早期基线的单幕 17 层、25×25 战场及 0–3 级高度。更大的网格用于完整多格占地和路线规划，三幕让同一防线持续成长并经历三种首领检验。

## 开局与路线

- 开局为 100 精神稳定、99 专注、20 带宽、深度 1；仓库有三个近战、三个远程和一个支援构造，尚未部署。
- 三幕为噪声边境 17 层、记忆工厂 16 层、统御核心 15 层，通关共完成 48 个节点。仓库、部署、耐久、资源与地形跨幕保留。
- 路线使用五条轨道，通常每层有 2–4 个节点；每幕第一层提供四个普通战斗，倒数第二层为营地，最后一层为首领。普通多节点层至少提供两类决策，固定层除外。
- 只能进入当前节点连接的下一层；确认后不能返回或跳层。节点显示类型、已知风险、收益和连接方向。
- 种子决定地形、路线、首领、遭遇、未知节点、商店与奖励。本局内容池也会保存，之后解锁局外内容不会重抽本局结果。
- 每幕从两名主题首领中选择一名，共六类首领。幕初、宝库附近与首领前逐步揭示机制。

| --- | --- |
| 第一幕 1–4 层 | 北 |
| 第一幕 5–10 层 | 北、西 |
| 第一幕 11–17 层；第二幕 1–4 层 | 北、西、东 |

## 战前部署与维护

战前是调整防线的阶段。开战后，部署、搬迁、撤回、维修、升级、融合、优先级设置和地形改造全部锁定。界面在开战前显示资源、带宽、仓库与入口编队情报。

左侧信息栏集中显示入口威胁、教学与构造详情，右侧保留完整战场区域，底部部署状态条显示当前位置是否合法、费用与带宽。信息栏可以独立滚动，各区域预留空间，不互相覆盖。拖出构造时，占地和射程随鼠标即时更新；打开确认窗口后，预览保持可见，战场暂时不接受操作。

选择或拖出仓库构造后，可预览完整占地、射程和可攻击区域。所有占地必须在场内、等高，且不能覆盖火种、入口或其他存活构造。远程只能部署在高度 1–4，近战只能部署在高度 0，支援可放在任意等高地面；斜坡格不能承载构造。预览同时以轮廓和文字说明合法状态、失败原因及部署后的带宽。

首次部署免费；已部署过的构造再次部署、搬迁或收回，要承担维护费的 15%，按规则取整并应用减免。确认窗口显示实际费用与位置，取消不扣专注、不改变原位置。维修按缺失耐久比例和维护费计价；维修已部署构造后，它回到仓库。耐久归零者停止作用，但仍可在允许维修的阶段恢复。

普通构造以 2×2 占地为主，大型构造使用 3×2、2×3 或 3×3。完整占地参与部署、地形与碰撞判断。范围预览和实际攻击调用同一规则。选中构造可查看属性、分支、目标类型、效果、耐久和带宽，并设置优先处理离火种最近、最远或当前生命最高的敌人。

## 地形、视线与镜头

持久战场为 41×41 微网格，高度 0–4。醒觉火种位于中央偏下的 5×5 保护区，入口同样受到保护。界面格坐标从 0 开始。

新局按种子生成不规则山脊、阶梯高台和弯曲谷道，同一种子可以复现同一地形。初始相邻格高差不超过一级，保留足够连续平坦高台供多格远程构造部署；北、西、东、南四个入口始终各有一条零高度通路连到火种。高地边缘仍按下述峭壁规则处理，斜坡由玩家铺设。

自然地形替代早期的固定方形岛与笔直十字道路。这个变化只影响新开的远征：继续已有 Web v2 存档时，原有地形、玩家改造、斜坡与损坏状态都原样保留，不重新生成。

工具提供单格、3×3 和五格直线笔刷，可升高一级、降低一级、铲平至 0，或铺设/调整斜坡。斜坡位于低侧格，朝向恰好高一级的邻格；重复同向操作可移除。每个实际改变格基础消耗 2 专注，再应用收藏品与天赋减免。保护格与被构造占用的格子不可改造。

整次笔刷先验证再作为事务提交。预览显示实际修改范围、费用、路径与屏障变化，非法时说明原因。战前可逐步撤销并退还原额费用；若后来部署的构造占用修改格，须先处理该占用。开战后清空撤销栈。

相邻等高格可直接通行；高差一级只有方向正确的斜坡能通行，其余高度边缘形成可破坏峭壁。地面敌人优先走通路；封路后选择总代价最低的破障路径，逐级击毁高侧地形，变化跨战斗保留。飞行敌人越过地形。

远程构造每高于目标一级获得 8% 射程和 10% 伤害，最多四级。直接攻击采用插值视线检测，较高地形能阻挡射击，自身高台边缘不会错误挡住向下射击；间接攻击忽略遮挡但仍检查射程。低处攻击高处时，每级高度差减伤 12%，穿甲只能将这项保护减半。对敌人护甲结算后，每次有效攻击至少造成攻击力的 5%；构造承受普通攻击至少损失 1 耐久。

镜头固定 55° 俯角、正交投影，像素单位随镜头选择八方向帧。设置中的画面渲染分辨率提供自动、960×540、1280×720、1600×900、1920×1080、2560×1440，选择后立即生效并保存。自动模式按实际显示尺寸适配设备像素密度，倍率上限为1.5；固定档位按窗口比例调整战场精度，较低档位节省绘制开销。单位图集独立使用最近邻采样，中文界面独立保持清晰，并支持100%/125%/150%缩放。窗口大小仍可自由调整。

路线、战前、战斗、奖励和菜单界面采用短暂交叉淡化，确认弹窗平滑出现和退出。转场期间暂时锁定输入，进入战斗的过渡结束后才开始计时；确认选择与安全存档立即生效。设置中的“减少动态效果”会关闭转场并减少战斗特效，界面转场也尊重系统的减少动态效果偏好。

## 带宽、升级与构筑

只有存活且已部署的构造占用带宽，仓库不占用。带宽枢纽等支援能提高有效上限，敌方干扰会降低它。战前不能主动超限。战斗发生过载时，按部署时间从新到旧禁用构造，直到满足上限；被禁用者保留位置与耐久，但停止攻击、修复、强化和带宽支援。上限恢复后自动重新启用，界面显示干扰与停机状态。

构造分 T1、T2、T3。T1 升 T2 必须选择 A/B，T2 升 T3 沿原分支发展；确认前可比较属性与效果。三个同类型、同阶构造可以融合，三个 T2 还必须属于同一分支。核心可保留位置，另外两个消耗；新耐久按三件材料的当前耐久占总耐久比例继承，不会免费回满。

目录包含 12 种构造、18 种普通与功能敌人、4 种精英、6 种首领、30 件收藏品、24 项天赋和 24 个事件。部分收藏品与事件通过局外解锁扩充后续单局池。构筑围绕高地远程、近战承伤、支援网络、远距离压力控制、低精神爆发和带宽扩张展开。收藏品和天赋不重复获得，条件与数值以图鉴及确认面板为准。

## 战斗与死亡压力

普通、精英和首领战分别分成 3、4、5 个连续敌群，间隔 4–6 秒，期间不能重新部署。精英在倒数第二群加入，首领在第四群加入。编队随幕与层数增长，功能敌人逐步加入；战前列出总数、类别、入口分布和到达时间。

模拟以固定 20 Hz 推进，绘制独立刷新；可暂停或选择 1、2、3 倍速度。同时活动敌人最多 100 名。召唤、复制、分裂共享不超过初始编队 10% 的确定性增援预算，耗尽后不再增殖。

构造自动寻找范围内、类型匹配且满足视线的目标。近战承受阻路压力，猎杀与攻城敌人能攻击更远的构造或快速拆解峭壁。治疗、护盾、加速、干扰、传送、增援、爆炸和精神攻击具有前摇与可辨识反馈。首领在约 70% 和 35% 生命进入后续阶段，已公开机制增强或组合出现。

普通敌人突破火种后造成精神伤害并离场；精英和首领留在火种继续攻击，仍可被选中。精神稳定降到 0 时立即失败。

击杀敌人也会产生死亡压力：

```text
距离衰减后压力 = 原始压力 / (1 + (距离 / 6)²)
最终伤害 = max(0, 到达火种的压力 - 当前抗性)
```

收藏品、天赋和支援按描述继续影响压力或抗性。记录会列出来源、原始值、距离减免、抗性吸收和最终伤害。远处消灭高压力敌人通常更安全；有关天赋以图标标记高压力目标，不能只看生命值决定击杀顺序。

## 战利品与精神深度

| 结果 | 基础恢复与收益 |
| --- | --- |
| 普通战胜利 | 恢复 8 精神，三幕分别获得 35/40/45 专注 |
| 精英战胜利 | 恢复 12 精神，三幕分别获得 80/90/100 专注 |
| 第一、二幕首领胜利 | 恢复最大精神的 20%，分别获得 100/125 专注，进入幕间奖励 |
| 第三幕首领死亡 | 恢复最大精神的 35%，立即胜利，不进入普通奖励流程 |

非首领战后从三个候选构造中选择一个加入仓库；战斗中每提升一级深度，额外获得一次构造选择。普通战有 20% 基础概率出现收藏品奖励，精英战保证提供。奖励按构造、收藏品、天赋的顺序领完，才能继续路线；保存后候选固定，刷新不能重抽。

深度 1 升 2 需要 200 经验，此后每级需求增加 125，最高深度 12。每次升级基础增加 5 最大精神、恢复 10 当前精神、增加 1 带宽和 1 抗性，相关收藏品可进一步改变收益。每达到偶数深度，从三个尚未拥有的天赋中选一个。

## 非战斗节点

| 节点 | 决策与离开方式 |
| --- | --- |
| 营地 | 恢复 30% 最大精神、免费维修一个构造、免费升一阶，三选一后离开；新版各压力等级一致 |
| 工坊 | 可反复支付专注维修或升级，主动离开后结束 |
| 商店 | 三个构造、三个未持有收藏品，基础售价 80/120 专注；可多次购买，货架固定 |
| 宝库 | 从候选收藏品中免费选一个；可用池耗尽时给予专注补偿 |
| 未知 | 按种子揭示为事件、普通战斗、商店或宝库，读取不能换结果 |
| 事件 | 两个明确选择，确认前显示精神、专注、带宽或永久效果的实际得失 |

营地与事件免费升级仍需选择合法构造及分支。商店收藏品来自本局可用且未持有的池，池不足时数量相应减少。事件造成精神耗尽也会失败，并单独记录事件伤害。

## 局外成长、保存与复盘

胜负均获得记忆碎片：每个完成节点 2、每个击败精英 5、每个击败首领 10，完整胜利额外 50；重复读取结算不会重复发放。六组内容解锁各需 30 碎片，扩充后续单局收藏品和事件池。发现记录与首领档案也会保留，不提高开局基础属性。

控制压力初始开放 0，通关当前等级后开放下一级，最高 10；已开放等级不会降低。新局在确认前展示累计敌人生命、攻击、速度、突破伤害、死亡压力、护甲和能力参数。压力 10 相对同幕同层标准属性为 3.20 倍生命、1.90 倍攻击、1.16 倍速度、1.65 倍突破伤害、1.60 倍死亡压力和额外 3 护甲。每级完整数值见[难度与平衡说明](DIFFICULTY_BALANCE.md)。

新版同种子同内容池、同节点的计划编队、数量、出场间隔与每种敌人的击杀经验/专注不变；营地各级恢复 30%，商店、维修与升级不因压力等级加价。难度不再通过提前投放后续幕敌人或削减服务收益来增加。实际路线、成长次数、增援和奖励领取仍取决于这一局的战况与选择。

压力 6–10 的减速和定身持续时间逐级缩短，最高缩短 25%。首领生命完整成长，受到的治疗与护盾按生命倍率的平方根成长；单个干扰来源在常规能力周期内保留至少 1.1 秒恢复间隔，多源仍可能重叠。高地、防护、抗扰中继与带宽余量继续有效。

压力 8 起，首领每 12 秒释放频震：预警 1.5 秒后，对标记位置 8 格范围内最多两座构造造成 55% 攻击力伤害，嘲讽构造优先，护甲和高地保护参与结算。蓄力期间首领停留在标记位置，玩家可在战前配置承伤者、维修覆盖和侧翼火力应对。

早期进度依次提示部署与带宽、地形与视线、死亡压力与抗性。教学可跳过，帮助与图鉴可再次查看。

只保留一个活动单局，新游戏替换前确认。路线、安全节点、成长、奖励和开战前保存；战斗中退出，继续时回到该场战前。部署、耐久、地形、资源、随机顺序与待领取奖励均恢复。Web 存档位于本机浏览器，使用同一浏览器和 4173 端口继续，不提供云同步。旧引擎与 Web v1 存档不自动转换，原数据不会因此被删除。

难度调整不重置现有 Web v2 单局。新局采用 `difficultyRevision: 2`；缺少该字段或标为 1 的旧局按旧难度继续，包括旧版的高压营地恢复降低、服务加价和编队变化，界面会说明旧规则身份。原有内容池、货架、奖励、碎片与已解锁等级保持不变。

第三幕首领死亡即胜利，精神稳定耗尽即失败。结算显示幕层、路线、完成节点、击败与突破数量、突破/死亡压力/事件伤害、构造损毁、过载、幸存构造、收藏品与天赋、核心伤害构造、三幕首领状态、重要选择和记忆碎片，并根据实际统计指出主要失败原因。

## 音乐与反馈

每种构造的 T1、T2A/B、T3A/B 具有不同机械结构，升级预览与部署后模型一致。首领随三阶段改变形态。敌人步行、履带/节段运动和飞行姿态随战斗推进，攻击与维修带有对应机构动作。暂停冻结实体动作、命中和消散；倍速同步加快。过载停机与损毁残骸停止动作，保留明确状态文字。

菜单、路线、战前、节点、奖励、胜利和失败使用对应音乐。战斗 calm/action 双层随危险度平滑混合，首领增强 action 与低频，暂停时降低音量；设置分别控制主音量、音乐、音效和界面音。

点击提示缩短为约 65 毫秒，部署提示约 180 毫秒，取自已授权音源的短片段，并经过低通及平滑淡入淡出。交互提示采用单声部替换，连续操作不会叠出长尾尖音；它们由“界面音”音量控制。

合法放置、选中、保护区、危险、停机与首领能力同时使用轮廓、图标、文字或动画表达。重要操作先预览、再确认、后反馈，取消不应留下扣费、原位置变化或战场输入残留。
