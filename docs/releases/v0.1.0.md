# 心域防线 v0.1.0

首个公开版本，提供游戏源码和 Windows x64 便携包。

## 下载与启动

1. 在本页 Assets 中下载 `Mindrealm-Bastion-v0.1.0-windows-x64.zip`。
2. 右键 ZIP，选择“全部解压”。
3. 打开解压后的 `Mindrealm-Bastion` 文件夹，双击 `启动游戏.exe`。

游戏会自动在默认浏览器打开。便携包包含运行时、音乐、字体和素材，解压后即可离线游玩。适用系统为 Windows 10/11 x64，需要现代桌面浏览器。

GitHub 自动生成的 `Source code (zip)` 和 `Source code (tar.gz)` 用于源码开发。直接游玩请选择带 `windows-x64` 的 ZIP。

## 便携包结构

```text
Mindrealm-Bastion/
├─ 启动游戏.exe
├─ 启动游戏.cmd
├─ README.txt
├─ MANIFEST.sha256
└─ game/
   ├─ web/
   ├─ assets/
   ├─ launcher/
   ├─ runtime/
   ├─ licenses/
   └─ version.json
```

`启动游戏.cmd` 是备用入口。移动游戏时，请一起移动整个文件夹。存档保存在本机浏览器中，继续游玩时使用相同浏览器与端口；默认地址为 `http://127.0.0.1:4173/`。

## 游戏内容

- 三幕、48 个路线层级，包含战斗、营地、工坊、商店、宝库和事件。
- 12 种心智构造，支持阶级成长、分支升级与融合。
- 28 种敌人，包含六类首领及其阶段外观。
- 地形改造、高地射界、带宽限制与死亡压力。
- 固定种子、战前存档恢复、结算复盘与逐级解锁的控制压力。
