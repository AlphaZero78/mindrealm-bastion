# 心域防线

《心域防线》是一款简体中文 3D 肉鸽塔防游戏。扮演“偏频者”，沿三幕、48 层分支路线收集心智构造，在持久的阶梯战场上规划通路、高地和防线，最终切断控制信号。

项目使用 JavaScript、Three.js、Canvas 和 Web Audio。游戏离线运行，战斗按固定时间步长计算；Windows 便携包内含本地运行时。

12 种构造具有各自的五种阶级／分支外观，37 种敌人包含六名首领的三阶段形态。实时金属模型具有连续步行、履带、悬浮、攻击和施法动作，暂停与倍速同步；详见[模型与动作说明](development/docs/ENTITY_MODELS_AND_ANIMATION.md)。

当前源码包含 36 幅事件 CG、12 幅精神使者 CG 和 108 个事件选择及对应的故事发展。画面采用自然摄影质感，以人物表情、动作和选择物件讲述遭遇；大型设施在需要时作为远处背景。事件按“阅读故事、确认选择、查看发展、继续前进”推进，枢纽同时展示使者场景和三份赠礼，详见[叙事与画面说明](development/docs/EVENT_PRESENTATION.md)。三入口战场、南侧火种、地形框选、追踪无人机、72 件枢纽赠礼与手动幕间推进见[战术规则更新](development/docs/TACTICAL_UPDATE.md)。已发布便携版的内容以 [v0.1.4 更新](development/docs/RELEASE_V014.md)为准。

## 启动

### 在线游玩

浏览器打开 [心域防线在线版](https://alphazero78.github.io/mindrealm-bastion/)，即可游玩当前已部署的发布版本。首次加载需要下载模型、音乐和插画。

在线版进度保存在当前浏览器中。在线网址与本地便携版使用各自的浏览器存储，继续游戏时请使用相同网址和浏览器。部署流程与本地预览见 [GitHub Pages 说明](development/docs/GITHUB_PAGES.md)。

### 下载 Windows 版

打开 [v0.1.4 发布页](https://github.com/AlphaZero78/mindrealm-bastion/releases/tag/v0.1.4)，下载 `Mindrealm-Bastion-v0.1.4-windows-x64.zip`。右键选择“全部解压”，打开解压后的文件夹，再双击 **`启动游戏.exe`**。游戏会自动在默认浏览器打开。

便携包适用于 Windows 10/11 x64，内置 Node.js 运行时、音乐、字体和素材，解压后即可离线游玩。请将入口与 `game/` 文件夹一起保留。GitHub 自动生成的 `Source code` 压缩包用于源码开发；玩家使用上述 Windows ZIP。

```text
Mindrealm-Bastion/
├─ 启动游戏.exe       双击进入游戏
├─ 启动游戏.cmd       备用入口
├─ README.txt         使用说明
├─ MANIFEST.sha256    文件校验清单
└─ game/             游戏内容、运行时和许可证
```

### 从源码运行

安装 [Node.js](https://nodejs.org/) 22 或更新版本，再执行以下命令。项目直接使用 Node.js 标准库，克隆后即可启动。

```sh
git clone https://github.com/AlphaZero78/mindrealm-bastion.git
cd mindrealm-bastion
npm start
```

在浏览器打开 `http://127.0.0.1:4173/`。服务只监听本机；在终端按 Ctrl+C 可停止服务。Windows 用户也可以双击根目录的 `启动游戏.cmd`，启动器会自动打开浏览器。

关闭网页后，再次启动可继续远征；战斗中途退出会回到该场战前。请使用同一个浏览器和端口，存档保存在该浏览器的本机存储中。旧 Godot 存档继续保留，新版采用独立存档。

### 构建 Windows 便携包

在 Windows 上使用 Node.js 24.12.0，执行 `npm run package`。构建工具会在仓库同级的 `game_build_release` 目录生成 `心域防线-Windows.zip`。打包复用已验证的源码，测试与资源审计由独立命令执行。详细步骤见[开发与验证](development/docs/DEVELOPMENT.md)。

将 ZIP 全部解压后，双击包内的 **`启动游戏.exe`**。便携包自带运行时，另有 `启动游戏.cmd` 备用入口。请保留同目录的资源、运行时与启动支持文件。

v0.1.1 的性能测量、画面一致性与项目审计见[审计报告](development/docs/PERFORMANCE_AUDIT_V011.md)。

v0.1.2 新增心神枢纽、36 件专属收藏品和整页节点布局；事件统一并入未知信号，地图纵向间距增至 136 像素。玩法变化、存档兼容和验收记录见[更新说明](development/docs/RELEASE_V012.md)。

## 开始第一局

1. 新建远征会随机生成 16 位字母数字种子，可点击“重新随机”或手动输入；同一种子决定相同战场、路线和奖励顺序。
2. 在心神枢纽接纳一份赠礼。三幕各有四位精神使者，每次随机遇见一位，从其六件专属收藏品中随机展示三件，再选择一件。
3. 在路线选一个可达节点，进入战前。仓库中的远程放高地、近战放地面，支援可放任意等高平台。首次部署免费。
4. 先看入口数量、敌群类型和到达时间，再确认开战。战斗中可暂停、加速，并使用道具处理危机。
5. 领取单位、收藏品、天赋与道具，再选择下一节点。顶部背包初始容纳 12 个构造（含已部署者）和 3 个空道具槽；战斗有概率掉落道具，构造超容量时须整理后继续。
6. 通过 36 个事件和扩充后的商店，选择补给、回收、扩容与成长；T2 / T3 分别在深度 2 / 5 开放。

WASD／右键拖动平移；使用地形框选时，左键拖动选区，右键拖动视角；R 旋转非正方形构造；Q/E 连续旋转；滚轮缩放；F 聚焦火种；右键单击／Esc 取消。战斗中空格暂停，1/2/3 切换速度。设置提供四路音量、自动或 960×540 至 2560×1440 画面渲染分辨率、100%／125%／150% 界面缩放、减少动态效果及浏览器全屏。画面设置即时生效并保存，界面切换与确认弹窗带平滑淡入淡出。

控制压力从 0 开始，通关后逐级解锁至 10。新局通过敌人生命、攻击、速度、护甲与高阶首领频震提高难度；同种子同节点的计划编队、数量、出场时间和击杀奖励不变，营地仍恢复 30%，服务不因压力加价。已有 Web v2 远征保留其原难度规则，新局采用规则修订 5：提高升阶和地形费用、减少战斗专注、增加高阶带宽占用，商店出售 6 件构造。同类光环取最强值，带宽中继限部署 1 座；24 条 T3 分支新增机制，36 个事件改为 108 个新选择。每级深度仍增加 3 带宽，T2 / T3 在深度 2 / 5 开放。当前数值、兼容范围与验收见[平衡与背包更新](development/docs/BALANCE_INVENTORY_UPDATE.md)。

## 项目结构

游戏与开发资料分别保存在两个独立目录，并一同纳入 Git：

- `game/`：玩家运行所需的页面、规则、模型、音频、字体、启动服务和授权说明。
- `development/`：开发约定、文档、测试、构建工具、模型原件和插画生成记录。
- 根目录仅保留仓库入口、包命令与 Git 配置。Windows ZIP 与在线版只导出 `game/` 的运行内容。

正式启动使用 `npm start`。开发验证使用 `npm run dev`，在 `http://127.0.0.1:4191/?qa=1` 打开内存存档的独立开发服务。正式服务与在线版均不提供调试接口；URL 查询参数不会开启开发模式。
