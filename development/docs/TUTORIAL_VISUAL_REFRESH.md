# 教程与界面更新

## 玩家体验

主界面新增“教程”入口。教程使用固定练习场，依次引导资源识别、地面近战部署、高台远程部署、单格地形改造、开战、暂停与倍速、领取奖励、路线选择和营地恢复。战斗包含 6 个敌人，之后只有一次三选一单位奖励。教程随时可以退出或重新开始。

教程的单局、局外进度和设置与正式远征分开。退出后恢复进入前的状态；在教程中修改设置只影响当前练习。正式存档的命名空间和版本保持原样。

102 件收藏品、24 项天赋、10 种道具和 12 位使者具有独立的彩色贴纸图标。58 个界面图标使用相同风格，包括精神稳定、专注、带宽和精神深度。图鉴、奖励、商店、枢纽、背包和构筑详情共用图标映射。

菜单、路线、奖励和面板改用蓝粉金属流动背景。整个窗口共用一幅背景，半透明阅读面板让纹理连续穿过页面。事件和使者的原有 CG 保留。小窗口通过现有滚动区域访问完整内容。

## 实现位置

| 文件 | 职责 |
| --- | --- |
| `game/web/core/tutorial.js` | 固定练习状态、步骤、动作限制和短编队；部署、地形、战斗及营地仍调用正式规则 |
| `game/web/tutorial-view.js`、`tutorial-style.css` | 分步说明、控件高亮、完整占地轮廓及准确点击光点 |
| `game/web/app.js` | 教程进入与退出、临时状态恢复、保存隔离及页面连接 |
| `game/web/view/sticker-icons.js`、`sticker-style.css` | 显式图标映射、实心 SVG 形状、配色、白边和小尺寸布局 |
| `game/web/view/metal-flow.js`、`metal-theme.css` | 全屏单画布、蓝粉金属着色、透明阅读层和生命周期 |
| `development/web-tools/sticker-icon-preview.mjs` | 将完整图标目录输出到指定的仓库外预览目录 |

图标在本地生成 SVG，页面复用形状代码。图标无需远程请求、滤镜或动画。新增收藏品或天赋时，应同步补充显式映射；目录覆盖测试会发现遗漏。

教程引导只在实际操作成功后前进。非法位置与取消保持当前步骤。确认弹窗出现时暂时隐藏引导层，保证按钮可达。部署光点对应实际落点格，外框表示整个构造占地。

## 性能边界

普通页面的背景最多绘制 180,000 像素，目标频率为 20 帧/秒；战场降为 90,000 像素和 10 帧/秒。隐藏页面和减少动态效果均停止调度。窗口缩放采用 120 ms 防抖；菜单和图鉴停止持续绘制隐藏战场。WebGL 上下文丢失后使用共享的 CSS 渐变，恢复后重新建立图形资源。

2026-10-25 在 RTX 5060 Laptop、Chromium 155、1920×1080、DPR 1 上抽样测量。每组约 1.6 秒，开启与静止背景使用相同场景。

| 场景 | 实际背景频率 | 背景 CPU 提交均值 | 画面帧间隔均值，开启／静止 | P95，开启／静止 |
| --- | --- | --- | --- | --- |
| 菜单 | 18.73 帧/秒 | 0.013 ms | 4.17／4.17 ms | 4.30／4.30 ms |
| 102 件收藏品图鉴 | 18.72 帧/秒 | 0.030 ms | 4.17／4.30 ms | 4.30／4.30 ms |
| 24 座构造、100 个敌人 | 9.93 帧/秒 | 0.012 ms | 5.80／4.64 ms | 8.40／8.30 ms |

战场样本暂停模拟，用于隔离渲染开销。CPU 提交时间只包含发出绘图命令的时间，GPU 执行时间由图形设备另行承担。这些短样本只说明本机的开销与频率控制；实际战斗流程由教程实战和整局通关分别验证。

## 验证入口

在独立开发服务的 `?qa=1` 页面，通过现有 Playwright CLI 执行以下脚本。结果与截图写到仓库外，验证使用独立内存存档。

- `browser-tutorial.js`：固定地图重启、真实点击部署、非法操作、取消、地形费用、实时战斗、奖励、营地、退出和存档隔离。
- `browser-tutorial-production.js`：在全新浏览器上下文中访问独立正式服务，核对练习前后所有本地存储字节，检查继续原远征。
- `browser-visual-refresh.js`：完整收藏品与天赋图鉴、奖励、商店、枢纽、构筑详情及小窗口菜单。
- `browser-metal-flow.js`：实际像素变化、帧率和像素预算、代表性负载、减少动态效果及图形上下文回退。
- `browser-full-run.js`：在同一 QA 页面分三幕运行，检查完整的 48 节点、三名首领和结算。

`tutorial.test.mjs` 覆盖教程成功、取消、失败和重启；`sticker-icons.test.mjs` 检查全部映射与实心图形；`metal-flow.test.mjs` 检查预算、隐藏与减少动态效果、上下文回退和资源释放。最终集中运行 `npm test` 与 `npm run verify`。当前验收资料保存在 `D:/game_build_archive/tutorial-visual-refresh-20261025`。

本轮 290 项测试全部通过；374 项必要资源、411 项哈希和 10 项许可证检查通过。普通远征完成三幕、48 节点、24 场战斗和三名首领，取得 `MINDREALM_BROWSER_48_NODES_WIN`，脚本、渲染和音频错误均为空。教程另通过实时战斗和正式存储隔离检查。完整图标目录已渲染检查；960×540 奖励页的滚动与点击、150% 界面设置下的引导位置和实际战场落点均可用。
