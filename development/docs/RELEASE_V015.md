# v0.1.5：敌人重制、文案与稳定性更新

## 玩家可见更新

37 种敌人采用独立的机械结构与关节动作，覆盖移动、攻击、施法、受击和死亡。6 名首领保留各自的三阶段形态。实时模型、静态图、动作图集、死亡图集和肖像使用同一模型来源。

模型修整覆盖全部敌人与 12 类构造。成对曲面部件采用真实镜像，同步处理法线和三角形绕序；底盘、支座、轮轴与升级模块按承重和连接关系整理。节拍增幅器的左右声学弧片、轮上结构和馈口行程一并修正。

游戏文案审校覆盖 2,620 项，调整 327 项文字。费用、作用对象、触发条件、持续时间、上限和选择后果逐项核对，并统一数字、单位和标点。控制密钥明确消耗 2 点永久带宽，共振风暴明确消耗一座库存构造、最多维修 3 座受损构造。

## 合并远端修复

本次保留远端 `2b449ae` 至 `a3517f5` 的 9 个提交，并合入本地模型、动画和文案更新。共同修改的 `battle.js`、`rules.js`、`save.js` 已合并。

- 地形生成复用固定旋转参数，保持随机调用和计算顺序。
- 同一构造行动阶段复用近、远目标排序，实时处理生命变化和分裂增援。
- 敌人单次遍历选择攻击目标，保留嘲讽、距离和同条件下的稳定顺序。
- 规则缓存比较原始状态值，并补齐精神低于 40% 时攻击加成的失效条件。
- 存档校验复用路线节点索引，拒绝损坏的嵌套结构与无效内容 ID；校验失败通过既有返回值报告，并保留有效存档。
- 修复目录迁移后的核心对照工具路径。

远端性能记录来自特定 CPU 模拟场景，详细环境与测量限制见[持续代码审计](PERFORMANCE_AUDIT_20261017.md)。游戏画面的实际帧率还受渲染、设备和场景复杂度影响。

## 存档与发行范围

Web v2 存档格式与 `mindrealm.web.v2` 命名空间继续沿用。已有远征保留原有难度修订与随机进度；在线网址和本地便携版分别使用各自的浏览器存储。

游戏运行文件位于 `game/`，开发文档、测试和模型原件位于 `development/`。两个目录都纳入 Git；Windows ZIP 与 GitHub Pages 只导出游戏运行内容、玩家说明和许可证。便携包内置 Node.js 24.12.0，解压后通过 `启动游戏.exe` 进入。
