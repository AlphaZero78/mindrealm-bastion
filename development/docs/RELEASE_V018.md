# 心域防线 v0.1.8

2026 年 11 月 3 日发布。

## 模型与画面

12 类心智构造、37 类敌人共 109 个外观采用完整模型，追踪无人机拥有独立模型。各外观包含七段动作，肖像和回退图集取自同一模型。制作源码随仓库提供，详见[模型与动作说明](ENTITY_MODELS_AND_ANIMATION.md)。

地形会正确遮挡接触阴影与底座的半透明底色。飞行单位的阴影按实际地面高度定位，高台侧面和前方高地按可见关系裁切阴影。

主菜单进入设置、图鉴等页面时，过渡层只采集可见战场，消除战场闪现。PV 播放界面保留影片时长，素材来源和授权信息保存在许可证文件中。

## 下载与存档

在线版：[心域防线](https://alphazero78.github.io/mindrealm-bastion/)。Windows 版从 [v0.1.8 发布页](https://github.com/AlphaZero78/mindrealm-bastion/releases/tag/v0.1.8)下载 `Mindrealm-Bastion-v0.1.8-windows-x64.zip`，完整解压后双击 `启动游戏.exe`。

本版沿用现有游戏规则和 Web v2 存档格式。在线版使用原网址，便携版使用原浏览器与端口继续远征。旧版下载保留。

## 验证与构建

模型接入已完成 109 个外观检查和 48 节点完整远征验证。阴影修复通过 17 个遮挡场景、图集回退和 220 实体同屏检查。发布前的 300 项自动测试全部通过，443 项必要资源、478 项哈希和 10 项许可证校验通过。上线后检查实际页面和发布清单。

Windows 包由 GitHub Actions 从发布提交构建，输出便携 ZIP 和 SHA-256 校验文件。在线版仅发布运行资源、玩家所需页面和许可证；模型制作工具保存在源码仓库的 `development/model-atelier/`。
