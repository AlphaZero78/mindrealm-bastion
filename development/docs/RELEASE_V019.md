# 心域防线 v0.1.9

2026 年 11 月 3 日发布。本版修正战场地形反馈，并优化事件抽取与选择。

## 地形与预览

攻击范围、支援范围、部署底框、地形改造标记和地面路线按可见地形顶面遮挡。升高、降低与铲平预览同步显示预期顶面和侧面；确认草稿后才修改战场并扣除专注。峭壁侧面阻止选中背后格子，火种、入口与图集部署预览也采用地形遮挡。

## 事件

本局已经出现的事件会从后续候选中排除。进入节点时，仅选择两个主要选项均满足费用、线索、材料、目标和容量要求的事件。候选不足时，未知信号揭示为普通战斗。

36 个事件提供 72 个主要决定，移除重复的数值交换与经验填充项。玩家也可通过独立的“保留资源，继续赶路”结束事件。事件已揭示后，选项和概率结果随存档保留。

## 下载与存档

[在线游玩](https://alphazero78.github.io/mindrealm-bastion/)与 [Windows 下载](https://github.com/AlphaZero78/mindrealm-bastion/releases/tag/v0.1.9)同步更新。下载 `Mindrealm-Bastion-v0.1.9-windows-x64.zip`，完整解压后双击 `启动游戏.exe`。

本版沿用 Web v2 存档。已经揭示的旧事件保持原目录和结算，后续节点采用新版事件。在线版请使用原网址与浏览器，便携版请使用原浏览器与端口继续远征。旧版下载保留。

## 验证

发布内容已完成 310 项自动测试覆盖、104 组地形与范围遮挡检查、39 组事件界面检查及 48 节点完整远征。原始证据来自集中回归与针对修订用例的复验。资源校验通过 443 项必要资源、478 项哈希和 10 项许可证。

Windows 包由 GitHub Actions 构建并提供 SHA-256 校验文件。详细规则、旧存档处理和复现脚本见[地形反馈与事件优化](TERRAIN_EVENT_UPDATE.md)。
