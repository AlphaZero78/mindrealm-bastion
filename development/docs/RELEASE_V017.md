# v0.1.7：内置游戏 PV 与引导教程

## 主菜单与影片

主菜单的“教程”和“游戏 PV”并排显示，保持原有菜单高度。PV 为 135 秒、1080p 的沧桑男声版，影片与封面均随游戏提供。网页首次打开时保持视频按需加载，Windows 便携版可离线观看。

播放器提供暂停、拖动进度、音量和全屏。关闭按钮或 Esc 返回菜单，并停止、卸载视频。观看期间菜单声音暂时静音，退出后恢复原音量；已有远征、局外进度和设置保持原样。加载失败时可点击“重试播放”。

本机服务器支持视频字节范围请求，拖动进度可直接读取需要的片段。在线版沿用 GitHub Pages 子目录部署，网页与离线包共用同一份视频资源。

内置视频约 43 MB，使用 H.264 编码并将索引前置，便于开始播放与拖动进度。原片继续保留，内置版的 AAC 音轨与已确认成片保持一致。

## 教程与界面

本版同步发布此前完成的固定地图教程、彩色贴纸图标、蓝粉金属流动背景和战斗敌群侧栏。教程覆盖部署、地形、战斗、奖励、路线和营地，练习状态与正式存档分开。详细范围见[教程与界面更新](TUTORIAL_VISUAL_REFRESH.md)。

## 下载与运行

Windows 玩家下载 `Mindrealm-Bastion-v0.1.7-windows-x64.zip`，全部解压后双击 `启动游戏.exe`。在线版地址为 [心域防线](https://alphazero78.github.io/mindrealm-bastion/)。旧版本下载继续保留。
