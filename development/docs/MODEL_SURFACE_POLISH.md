# 模型曲面与装配细修

本文保留第一次曲面细修的过程和验收数据。后续装配与图集记录见[模型对称与装配层次](MODEL_SYMMETRY_AND_ASSEMBLY.md)。

## 本轮范围

2026-10-15，三个子 agent 分组修整 37 种敌人，主进程处理共用源网格、轮胎和最终审查。主进程已查看全部 49 种敌人阶段外观的正面、背面和工作姿态，也查看了 12 类 T3 建筑。

本轮保留全部关节位置和父子关系。步足、攻击机构和首领阶段继续使用原有动作；轮胎接触计算对应新的 64 段轮廓。原始 Kenney 源网格与许可证保留。

## 共用网格

近景机械边缘使用五段倒角。圆筒按源网格的轴向截面细分；拱顶和凹面碟使用保留面板边界的曲面细分。加工后的网格保持原装配包围盒。

机桶和机柜的装饰电缆在归一化前筛除。保留几何重新居中，使轴套、腿壳和关节共轴。两级细节网格来自同一归一化模板。

17 种轮式敌人的基础外观共含 92 个主轮。新轮胎保留原铸造轮芯，增加圆弧胎肩、胎纹、凹入式轮辋和紧固件。近远景共用 64 段接触轮廓，轮胎采用哑光橡胶材质。重复的外叠轴盖已清理。

## 资源和复现

运行模型包含 50 个 GLB。`refine-model-surfaces.py` 定义曲面与轮胎处理，`export-realtime-models.py` 导出两级几何。`bake-entity-art.py` 保留源导入与建筑配方，历史图集需显式选择 `--legacy-reference`。

全部 49 类实体的当前图集由实际 EntityRenderer 生成。圆轮的 80 像素轮廓变化较小，轮部验收另外固定机身位置、时钟和速度，以 512 像素近景检查不同实际行程下的轮毂转动。接地和无滑动继续按真实 GLB 顶点验证。

源文件、派生网格及图集哈希记录在 `development/assets/model_sources/SURFACE_REFINEMENT.json`。替换前资源、原始报告和压缩审查画面保存在 `D:\game_build_archive\model-polish-20261015`。

## 最终验收

全部 49 类实体的 184 张运行 PNG 已安装，包括静态图、动作图、肖像和 37 套敌人死亡图。8,720 个存活动作格的尺寸、内容和透明留边检查通过，最小留边为 5 像素。17 类轮式敌人的近景滚动响应均通过；各外观两帧间改变 400～5,317 个像素。7 类飞行敌人另有速度指令响应记录。原始全量检查后，仅对新增滚动证据和定向修正项进行了复核。

集中执行一次 `npm test`，268 项全部通过。`npm run verify` 通过 366 项必要文件、411 项 SHA-256 和 10 份许可证检查。`git diff --check` 通过。

独立浏览器验证使用压力 0、种子 `reference-0`，完成 48 个节点和三场首领战，进入胜利结算。每幕普通战和首领战均采集实际 RAF 动作，显示时钟误差为 0；较长战斗的其余部分使用 QA 固定步长推进。画面与音频错误列表为空。另一独立页面主动关闭 WebGL，确认 49 套动作图和 37 套死亡图加载，37 类敌人的后备绘制、10 个死亡样本及减少动态效果的固定末姿均通过。

性能样本使用 Windows、Chromium、RTX 5060 Laptop、ANGLE D3D11，同时显示 24 座 T3 构造、100 个移动敌人和 96 架无人机。预热 45 帧后测量 180 帧：

| 窗口 | CPU 绘制中位数 / P95 | RAF 间隔中位数 / P95 |
| --- | --- | --- |
| 1440×900 | 4.3 / 5.2 毫秒 | 6.0 / 6.1 毫秒 |
| 1920×1080 | 4.1 / 4.6 毫秒 | 6.0 / 6.1 毫秒 |

1920 场景含阴影共 442 次绘制调用、12,442,168 个三角形，20 个实体使用近景模型，200 个使用远景模型。相机投影误差小于 6.4×10⁻¹³ 像素，渲染错误为空。该样本衡量本机渲染开销；完整战斗 AI 开销和其他显卡性能需按相应环境测量。
