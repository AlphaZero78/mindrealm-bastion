# v0.1.4：叙事、构筑与发行边界

v0.1.4 汇总已完成的叙事画面、操作与规则修订，并将玩家运行文件和开发内容分成两个独立目录。游戏内容位于 `game/`，开发约定、文档、测试、构建工具、原始模型和生成记录位于 `development/`；两者都纳入 Git。根目录只保留仓库与启动入口。

## 玩家可见更新

- 36 幅事件 CG 与 12 幅精神使者 CG，围绕人物、行动和选择物件展示故事。
- 事件先阅读、再确认、展示实际发展后继续；新规则下有 108 个选择，包含条件、线索、风险和后续遭遇。
- 新局自动生成 16 位字母数字种子，可重新随机或手动输入。相同种子保持地形、路线与奖励顺序一致。
- 右键拖动平移视角，左键框选地形；商店、工坊、营地与宝库采用横向布局和内部滚动，路线侧栏居中。
- 新局采用规则修订 5：提高升阶和地形成本、减少战斗专注、提高高阶构造带宽、商店提供 6 件构造；同类光环取最强值，带宽中继限部署 1 座。
- 24 条 T3 分支增加战术机制，降低单纯数值成长。详细数值与取舍见 [平衡更新](BALANCE_INVENTORY_UPDATE.md)。

已有 Web v2 远征保留原有难度修订、事件选择、商店货架与随机进度。正式存档继续使用 `mindrealm.web.v2`；离线地址与 GitHub Pages 使用各自浏览器存储。

## 代码与仓库审查

本次检查覆盖模块依赖、启动链路、静态服务边界、Windows 和 Pages 导出、资源清单与许可、存档入口，以及近期规则和界面调用链。审查以以下可验证结果落地：

1. 从正式应用移除 `window.__mindrealm`，正式服务器仅开放页面、资源和许可证。`qa=1` 与旧开发环境变量均无法打开开发接口。
2. 独立开发服务动态注入内存存档和验证桥接，仅开放指定帮助模块与环境贴图制作入口；使用独立端口和服务标识。
3. Windows 与 Pages 共用运行文件白名单，拒绝符号链接、开发目录、生成记录、旁文件与未登记素材。
4. 288 项运行资源、72 项模型原件及其许可和必要授权文件均有清单；迁移后合计校验 373 个哈希。所有运行模块和开发模块的相对导入均可解析。
5. 确认无引用的旧素材、旧引擎缓存、导入旁文件及过期一次性工具已送入回收站。可重新生成的包、日志和截图保存在仓库外。
6. 保留核心回归测试、仍有独立覆盖价值的浏览器检查和继续制作所需素材原件；清理前完整源码与工作文件备份保留在仓库外。

这是针对本次版本的代码与交付审查，验证范围由下列记录界定。
