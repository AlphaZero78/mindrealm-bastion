# v0.1.3：写实科幻 CG 与三入口战术更新

本版将 36 个事件的场景 CG 统一改为写实科幻风格，并纳入事件故事、实时模型和三入口战术更新。Windows 便携包包含运行时、音乐、字体与所有图像资源，解压后可离线游玩。

## 三幕场景

噪声边境以废土聚落、赛博黑市、断裂交通设施和荒废信号站为主。记忆工厂使用大跨度流水线、冷却设施、记忆回收设备和工业城区。统御核心突出控制巨构、数据深井、广播阵列和接近城市尺度的机械设施。

场景通过金属磨损、混凝土、液体、雨雾与实际光源表现材质和尺度。人物退到环境中的适当位置，保留银面商人、记忆容器、维护设备等事件要素。关键视觉集中在左中部，右侧选项和左下故事保留阅读空间。

36 幅原始 PNG 位于 `assets/game/events`，实测均为 1672×941，合计 86,262,266 字节。全部图像已逐张检查，保留原始生成字节。内置 ImageGen 的 45 次生成或编辑记录、完整提示词、实测尺寸与 SHA-256 位于 `development/assets/event_art/prompts.json`，同时保留前一轮图像的来源记录。事件名称、故事和实际得失继续由游戏内容与规则提供。

## 战场与构筑

- 北、西、东三个入口的位置随种子变化，醒觉火种位于南侧。五类地貌提供不同高台和通路，支持拖动框选地形、整笔确认及撤销。陆路与飞行路线分别显示名称和数量。
- 攻击范围与支援光环分开显示；升级差异使用金色粗体。构造描述直接展示当前总效果，敌人行为默认展开，紫色经验条位于精神深度旁。
- 已部署和损毁构造计入背包，每升一级深度基础增加 3 带宽。删除已部署构造前显示位置与防线变化，取消保留原状。
- 无人机织机发射可见的追踪机体，命中时结算伤害。新增九种敌人，三幕使用不同编队；第二、三幕进一步增加敌人生命和攻击。
- 事件交换的风险与收益提高，恢复显示完整整数并在生效时受上限约束。12 位使者各有六件专属赠礼，每次随机展示三件，再选择一件。
- 首领击败后继续等待余敌清理。前两幕领完奖励后播放幕间动画，点击按钮才进入下一幕。地面首领连续攻击构造后会预警并短暂破阵，避免维修防线形成永久僵局。

12 种防御构造和 37 种敌人合计 49 类实体、109 种阶级或阶段外观。实时机械模型使用有许可的 Kenney 零件，具有连续动作、暂停与倍速同步。详细规则与性能边界见[战术更新](TACTICAL_UPDATE.md)和[模型与动作](ENTITY_MODELS_AND_ANIMATION.md)。

## 保存与升级

在同一浏览器、同一 4173 端口游玩，可继续原有 Web v2 远征。旧局保留原地形、编队、事件数值与成长规则。新开一局采用规则修订 4，启用三入口、新敌群与新版成长。已有构造继续保留，构造总数超出背包容量时先整理再前进。

战斗中退出后回到该场战前。事件发展、奖励候选和幕间等待均可继续；新开一局会先提示替换现有进度。
