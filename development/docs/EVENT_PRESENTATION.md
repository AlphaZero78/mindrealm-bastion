# 事件与枢纽叙事、随机种子和实时模型

事件采用场景叙事页：左中部展示 CG，左下展示故事，右侧展示行动。顶部保留资源和升级经验。确认行动后，故事与结果区切换到对应发展，继续后进入奖励或路线。后续范围、事件数值、三幕敌群与幕间流程见[战术更新](TACTICAL_UPDATE.md)。

## 内容与保存

36 个事件各有独立 CG 和开场故事，共 84 条选择后的发展。故事使用本作的精神控制、记忆、频率与醒觉火种设定。右侧保留实际费用、收益和选材控件，条件不足时同时显示原因与不可用状态。

事件必须完成一个选择。首次点击行动框后，框体向下展开“再次点击确认”；再次点击同一行动才执行效果。点击空白处或按 Esc 可收起提示，切换材料也会取消待确认状态。首次点击和取消均保留全部资源与材料。确认后效果只执行一次，结果立即保存；继续游戏恢复同一段发展。领取奖励必须先阅读发展并点击继续。致命交换立即结束远征，失败页保留选择与实际得失。

数值与结果由 `web/core/state.js` 和 `web/core/event-balance.js` 计算。`web/core/event-stories.js` 负责叙事，`web/event-view.js` 消费真实预览和已保存的结果。存档版本仍为 Web v2，未决的旧事件正常显示选择页。

## 事件界面与点击反馈

2026-10-06 的界面采用居中 CG，宽、高均为原舞台显示框的 80%。同一张图铺成模糊背景，前景四边渐隐到背景。左下的青绿色标题条从屏幕边缘伸出，正文直接显示在虚化背景上。

右侧行动条写出具体行动名称，下方显示实际得失。淡色箭头使用圆润线端和转角。条件不足时保留原因提示，已展开的行动显示“再次点击确认”。

每个行动预留确认提示的空间。展开、收起与切换仅改变待确认选项的外观，其他选项保持位置和字号。舞台使用 `overflow: clip`，避免浏览器将超出的雾化背景当成可滚动内容。展开动画只裁切和淡入提示，按减少动态效果设置直接显示。

待确认状态仅存在于界面中。重新渲染或恢复进度后，玩家重新点击两次即可确认；已确认的故事结果沿用原有存档机制。

## 人物与叙事镜头

2026-10-05 的 CG 重绘涵盖 36 个事件和 12 位精神使者。画面以人物的表情、动作及选择道具为主体，采用自然光、正常对比、柔和的光学细节和景深。生活空间、工作台、门口、车厢与临时设施承担叙事；高架和大型工业设施只在剧情需要时成为背景。

事件图停在选择发生之前。例如，噪声黑市中的手尚未接过玻璃瓶，控制密钥仍未插入接口，窄带通道前的人物仍在观察旁路。图中的关键表情与动作位于左中部，右侧选项和左下故事延续既有结构。结果页保留这幅遭遇图，并显示已确认的 84 条后续故事之一。

每位使者都有一幅与职责对应的 CG。望隙者调焦观测器，守诺人加固护板，续火医师修复便携火种，拾忆童子拼接记忆片；其余使者分别通过测绘、通信、监听、救援、校准、访谈、档案交接和出发前的准备展现其设定。枢纽左侧展示完整图片、身份与台词，右侧并列展示三份赠礼。赠礼与路线继续使用原有图标作为识别标记。

原始 PNG 分别保存在 `assets/game/events/` 和 `assets/game/nexus/`。两组完整提示词、生成与编辑步骤、原始文件名、视觉检查和 SHA-256 位于 `development/assets/event_art/prompts.json` 与 `development/assets/nexus_art/prompts.json`。图片通过内置 ImageGen 制作，运行文件保留生成结果的原始字节。`web/view/nexus-art.js` 统一使者图片与场景说明，资源索引从该表收集所有枢纽 CG。

## 新局随机种子

打开“新建远征”时，表单生成 16 位字母数字组合。玩家可以点击“重新随机”，也可以填写自己的种子；确认空白输入时会重新生成。取消保留原单局，继续游戏使用存档中的种子。

`web/run-seed.js` 从浏览器随机源生成种子，确保字母与数字同时出现，并跳过会产生取模偏差的字节。手动种子、日期格式的旧种子和保存内容仍按原有确定性算法生成路线、地形与奖励。随机源只在填写新局表单时使用。

## 经验与模型

紫色经验条常驻于顶部精神深度旁，显示已得经验与升级要求。战斗、路线、枢纽、事件、奖励、幕间和结算均可查看，收起战斗操作栏也保留。到达深度 12 后显示满格与最高深度说明。

49 类构造和敌人使用实时金属模型，共 109 种阶级／阶段外观。材料具备环境反射、磨损、粗糙度和法线，近景使用倒角网格。连续关节动作配合显示插值，暂停和倍速同步。49 个零件复用实例合批，远景降低几何复杂度，隐藏战场停止持续绘制。

模型结构、制作命令与性能范围见[模型和动作](ENTITY_MODELS_AND_ANIMATION.md)。事件与使者的两组 CG 原图、完整提示词和哈希位置见上文“人物与叙事镜头”。
