# 游戏内文案审校

## 范围与方法

2026-10-15，使用 Qoder 中的 Kimi-K3（模型标识 `kmodel_latest`）审校游戏内中文文字。范围包含游戏介绍、操作指南、构造与敌人说明、收藏品、天赋、事件、操作提示、存档提示和结算文字。

语料共 2,620 项，分为 11 批，由 4 路独立 K3 会话并行处理。固定名称、代码匹配文字和动态内容受到保护。模型建议经过人工复核，最终调整 327 项，涉及 21 个运行文件。

文案采用短句和直接表述，统一数字、单位、标点及中英文间距。触发条件、作用对象、费用、概率、持续时间、上限、叠加规则和选择后果逐项保留。`autocorrect` 在本机不可用，排版由本地文字检查和人工复核完成。

## 关键修正

| 场景 | 修正后的信息 |
| --- | --- |
| 控制密钥 | 选项明确写出让出 2 点永久带宽，与实际消耗一致。 |
| 共振风暴 | 明确消耗一座库存构造，最多修好 3 座受损构造并送回仓库。 |
| 抗性腐蚀 | 保留降低 2 点、持续 5 秒、预警和多名敌人效果叠加。模型删去这些信息的建议已纠正。 |
| 成长说明 | 明确首次升级需要 400 经验，并补明 T2 融合要求同分支。 |
| 地形改造 | 说明费用按累计格子修改次数计算，同一格重复修改也计数。 |
| 收藏品与道具 | 补明最大生命、最大耐久、本局首次、本场临时抗性等限定；装甲涂层统一使用“护甲”。 |
| 道具与退出 | 明确道具在战斗胜利后可能获得；战斗中退出时，效果与消耗一并回到战前。 |

事件叙事保留原有场景、人物和选择反馈，修正了指代不清、被动句、重复表达及含糊的资源名称。

## 验证记录

写入前检查了动态占位符、数值、HTML 结构和源码快照。20 个 JavaScript 文件在排除文字节点后，执行语法树与修改前一致。游戏规则和效果数据保持一致。

集中执行一轮 271 项自动检查：270 项通过；一项旧断言仍使用“1.2秒”。断言同步为“1.2 秒”后，相关测试定向复查通过。资源检查通过，覆盖 367 个必需文件、411 个哈希和 10 份许可证。

浏览器检查覆盖 36 个事件、108 个选项及 6 组确认、取消和结果流程，并检查了 960 × 540 与 1440 × 900 下的操作指南。未发现文字截断、动态占位符泄漏、资源缺失或页面错误。已实际查看说明、选项确认和事件结果画面。

最终对局完成 48 个节点，击败噪声母巢、记忆重铸机和合唱监管者，正常进入胜利结算。路线由界面操作推进，战斗采用固定步长加速，并记录 6 段实际浏览器动画帧。页面、渲染和音频错误均为 0。所有浏览器检查使用独立的 `?qa=1` 内存存档。
