# 交互与画面更新

## 本次变化

2026-10-02。以下改动覆盖本轮十项体验要求，沿用当前 Web 版三幕远征、地形和构筑内容。

| 要求 | 实际行为 |
| --- | --- |
| UI 与美术 | 面板、卡片和弹窗使用圆角；控制按钮和罗盘使用圆形；路线节点使用六边形。保留已有授权模型、动画、字体和音乐。 |
| 路线页 | 移除右边栏。悬停或聚焦节点显示风险、收益和连接；点击可达节点直接进入。沿用短暂转场，提供减少动态效果设置。控制源情报可从顶部按钮打开。 |
| 地图移动 | 路线图和战场均支持左键拖动。超过 5 像素的移动识别为拖动，松开后保持当前位置；短点击执行选择或部署。WASD 速度从 120 提高到 150 像素／秒。 |
| 支援覆盖 | 单独计算友军作用范围。范围内可维修或受局部增益的构造显示青色占地与轮廓；停机、损毁的支援停止提供高亮增益。带宽、抗性等全局效果用文字注明。 |
| 空间遮挡 | 地形按深度绘入缓存。需要遮挡的实体先在独立小画布绘制，再裁去前方地形遮住的部分；已有场景像素保持原有顺序。 |
| 构造旋转 | 非正方形构造按 R 旋转 90°，完整占地、中心、射程和碰撞同步更新。已部署构造先进入搬迁预览，确认支付维护费后生效；取消保留原状。方向随存档保存。 |
| 批量改地 | 连续操作暂存为草稿，支持撤销一笔、取消全部和一次确认。路径随草稿更新，确认前保持真实地形与专注。 |
| 工坊 | 已部署构造优先排序，并显示高亮边框和文字标记。维修后回到仓库，列表随实际状态更新。 |
| 分支升级 | 并列展示当前与下一级效果，列出六项属性及变化值。日常描述只解释当前效果，移除全部等级的倍率堆叠。 |
| 底部栏 | 可手动收起、展开。开战后自动收起仓库和地形工具，保留速度、暂停和展开按钮。 |

## 计价与兼容

本场战前的前 20 格次按 2 专注／格计价，第 21～40 格次按 3 专注／格，此后每 20 格次增加 1 专注。一次笔刷跨越档位时逐格累计，再应用减免。每次实际改变计为一个格次，分开确认延续累计数量。

这项规则用于增加大量重塑地形的代价，保留小规模修整的原有费用。新战场准备阶段重置计数；整批撤销退还原额费用并恢复计数。例如，连续修改 27 格的基础总价为 61 专注。

草稿只存在于界面内存，确认后才写入本局。旧存档缺少方向或计价计数时，分别按 0° 和首档处理。已确认地形、路线、资源和奖励顺序继续保留。

## 验证结果

- 175 项 Node 测试通过，包含旋转后的完整占地、旧存档兼容、原子提交、跨档价格、失败与取消，以及支援距离和真实维修的一致性。
- 28 项浏览器交互检查和 6 项批量改地检查通过。检查包含 1920×1080、1366×768、960×540 窗口；未记录脚本错误或失败资源请求。
- 六个镜头角度通过像素回归：绘制实体后，实体矩形之外的地形差异均为 0。实际查看了四个方向的战场截图。
- 120 局规则模拟正常结束，20 个标准参考种子全部完成 48 节点和 3 名首领；另外 100 局为 57 胜、43 败，其中 20 个空阵均败。源码哈希守卫与失败列表为空。
- 浏览器通过逐节点交互完成三幕、48 节点和胜利结算。部署采用合法参考策略，战斗采用实际固定步长模拟加速；本项属于自动化流程验证。
- 压力场景保持 35 座构造、100 个活动敌人及 6 名首领，连续旋转镜头并每秒刷新 4 次地形缓存，采样 1000 个帧间隔。1920×1080、Chromium 154、RTX 5060 Laptop 上平均 52.13 FPS，1% low 为 34.70 FPS；绘制耗时平均 7.06 ms、P95 为 11 ms。极限场景仍有掉帧，尚未达到稳定 60 FPS。
- 更新后的 Windows ZIP 包含 135 个文件，269 项独立解压验证通过，覆盖中文空格路径、哈希、内置运行时、EXE 启动、重复启动复用与备用 CMD。发布目录内的 20 个 Web 文件与当前源码哈希全部一致。

额外的一次 EXE 隔离服务启动被自动审批以“策略阻止”拦截，该次动作未执行。既有解压验证已完成，额外的解压版浏览器复测未执行；交互与画面证据来自同源码的独立 QA 服务。

验证使用独立端口和内存存档，未访问玩家真实存档。原始日志与截图保存在系统临时目录的 `mindrealm-experience-qa` 中。发布包与验证临时文件均位于源码目录外。
