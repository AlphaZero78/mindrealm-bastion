# v0.1.6：事件与精神使者 CG 更新

## 画面更新

本次按 48 项最终审核选择更新叙事插画：替换 25 幅事件 CG 和 6 幅精神使者 CG，保留选定的 17 幅原图。新图中，16 幅来自 Codex 内置 ImageGen，15 幅来自 Cursor GenerateImage。

画面围绕当前故事补充人物动作、关键设备与科幻环境。更新涵盖废弃中继、控制密钥、频率双生、记忆压缩机、晶图师和残曦等场景。

全部图片保留原生尺寸与比例。PNG 保留原始字节，JPEG 按相同 RGB 像素转存为 PNG。最终选择、生成来源、提示词记录和替换前后的 SHA-256 保存在 `development/assets/`，运行路径保持一致。

## 存档与发行范围

本次继续沿用 v0.1.5 的玩法、数值与 Web v2 存档。在线版和 Windows 便携版使用同一套 CG；各自的浏览器存档继续保存在原位置。

Windows 版适用于 Windows 10/11 x64，内置 Node.js 24.12.0。解压 `Mindrealm-Bastion-v0.1.6-windows-x64.zip` 后，双击 `启动游戏.exe` 进入游戏。发行包与 GitHub Pages 只包含运行文件、玩家说明和许可证。
