# 心域防线 v0.1.1

本次发布包含界面与操作更新、性能审计和稳定性修复。运行素材、战斗数值及存档格式沿用现有版本。

## 下载与启动

下载 `Mindrealm-Bastion-v0.1.1-windows-x64.zip`，全部解压后双击 `启动游戏.exe`。Windows x64 便携包内含运行时、模型图集、音乐和字体，可离线游玩。请保留同目录的 `game/` 文件夹。

发布页的 `Source code` 压缩包供源码开发使用。玩家应选择带 `windows-x64` 的 ZIP；旁边的 `.sha256` 文件用于校验下载。

## 操作与画面

- 圆角面板、圆形控件与六边形路线节点；悬停节点看详情，点击可达节点直接进入。
- 左键拖动路线图和战场，WASD 平移速度提高 25%；非正方形构造可按 R 转向。
- 支援范围与受益构造高亮；修复后方地形覆盖前景的遮挡问题。
- 连续地形改造可先编辑草稿、再一次确认；累计大量改造后阶梯计价。
- 工坊优先突出已部署构造；分支升级比较当前与下一级效果。
- 底部操作栏可收起，开战后自动收起并保留战斗控制。

## 性能与稳定性

绘制期间复用单位属性，减少构筑效果枚举、射线判定字符串集合与地形临时数组。动态压力样本的平均绘制耗时从 8.75 ms 降至 7.20 ms，约降低 18%；整体帧率提升有限，极端负载仍会掉帧。

修复本地资源服务的编码路径越界问题，增加 HEAD 与 ETag 支持；强化异常存档的字段检查；修复 Windows PowerShell 5.1 音频验收脚本对 stderr 的处理。

## 验证

- 180 项源码测试通过。
- 60 组画面与实体几何逐项一致，沿用相同素材、分辨率和特效。
- 9,600 次攻击判定、240 组构筑效果、六局完整远征与优化前一致。
- 120 局模拟正常结束；真实浏览器完成 48 节点与最终胜利结算。
- 194 项浏览器交互检查、25 项启动器检查通过。
- 120 项必需资源、173 项哈希及 7 项许可证检查通过；两条战斗音乐的响度、峰值和同步时长通过。

详细测量方法、固定战况测试的有限收益及兼容说明见[项目审计报告](https://github.com/AlphaZero78/mindrealm-bastion/blob/v0.1.1/docs/PERFORMANCE_AUDIT_V011.md)。性能基线为此前已完成交互改进的本地版本。

更换版本前，请结束旧目录对应的后台游戏服务。启动器会复用默认 4173 端口上的有效服务；继续游戏请使用相同浏览器与端口。
