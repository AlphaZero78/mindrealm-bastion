# 记忆医师

## 当前结构

模型包含 39 件部件。四足承载单层底壳与淡色救治匣。顶部两枚药剂芯略高于匣顶，中央压泵保持独立行程，前部双臂携带凹面输注头。

## 对称性与装配层次

四足、操作臂、腕部输注头和药剂芯采用真实反射。两枚药剂芯的几何位置配对，发光与金色分别表示工作药剂和备用药剂。右臂承担接触攻击，左臂配合承载。

删除药剂外侧重复套筒、四个踝架、两个肩部叠环和藏在匣内的后调压机。单层底壳和平底靴减少零碎翼片；腕部保留必要的密封连接件。

## 动作与复核

保留四拍步态、三足承重和双臂展开。治疗仍在预警后恢复六格内敌人 9% 最大生命，包括自身。抽泵、压泵、器械回收、受击和死亡沿原关节工作。

主进程查看双肩、双肘和输注头是否对应，药剂芯与压泵是否各自清楚，以及前摇末端和释放首帧的连接。四足底面保持原接地高度。关节与动画保持原值。
