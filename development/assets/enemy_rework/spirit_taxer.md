# 精神税吏制作说明

宽体悬浮征收艇承载审计压机、双采集碟和并排账目储匣。

## 装配与左右对称

完整艇壳作为唯一主体。采集臂采用连续承力壳，四角喷口使用一体管壁，储匣保留完整本体。鼻部叠加护脊、储匣扣片和喷口重复护唇已收掉，后舵独立安装。

双采集碟、臂座、内拉计量器、后储匣和四角喷口按真实 X 镜像安装。原有外展角与计量器轴向采用对应反射角。

左右结构保持对称。前鼻接触器、中央审计压机和后驱动盘按各自职责分层。

## 动作与阶段

模型共 45 件、21 个关节。 关节坐标、父子关系、动画输入和原有工作行程保持原值。

飞行、抵达火种后的持续攻击及腐蚀抗性行为保留。实际 1.1 秒预警、5 秒腐蚀持续状态和尾段回收继续驱动采集、计量和压机。

## 素材与审查

部件继续引用 `models.json` 中已登记的许可源。承重面与护板采用 `corridor_wall`；实际导筒、门架、机匣和凹面装置保留各自完整源结构。原始 Kenney CC0 网格与许可证保留在 `development/assets/model_sources/kenney/`。

前上方检查双碟与臂壳的反射关系；后侧检查储匣与独立稳定舵；腹侧检查四个连续喷口与鼻部导套。

主进程统一编译并检查实际 PBR 画面，重点覆盖静止前后视、移动中的能力准备、释放与死亡姿态。
