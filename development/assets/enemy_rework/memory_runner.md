# 记忆赶工者制作说明

本轮从 42 件收为 31 件。四组髋、膝、踝关节、腿段长度和足底坐标保持原值，原行程驱动及逆运动学动作保留。

一片底框托住完整工厂装甲壳和后背驱动电机。左右飞轮统一圆形来源和尺寸，分别保留原调速与离合关节；两侧护盖改为单片折边结构。删除重复后置压力罐、冲头叠架和前方小镜片，前端保留一块狭窗、一只导套、一根捕获活塞及宽短冲头。

每腿从七件收为五件：髋轴承、完整股套、膝轴、完整胫套和单片跑鞋。侧面细导筒和踝饰圈已删除。左右全部腿件、飞轮和护盖使用 `handed(piece, side)`；圆轴件的源底面按轴向半厚度安装，使左右轴心与原关节重合。

原冲刺预警、压低胸壳、开盖、持续跑动和卸载死亡动作保持。主进程重点检查前后视腿部镜像、两侧飞轮的中心、支撑脚底面、冲头与导套同轴，以及最大抬膝、冲刺低姿和死亡末帧的壳腿间隙。实际材质与连续动作由主进程统一检查。

部件来自已登记的 Kenney Space Kit 与 Tower Defense Kit CC0 网格；原始素材和许可证保留在 `development/assets/model_sources/kenney/`。
