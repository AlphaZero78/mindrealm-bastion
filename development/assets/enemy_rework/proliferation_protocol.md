# 增殖协议体制作说明

六轮压力分发车以穹顶壳、后压力柱和前分发口形成轮廓。

## 装配与左右对称

折边底盘直接承接轴桥与压力壳。前分发口使用上下整面快门，低位接触头采用连续承压板。两侧供压管沿 Y 轴布置，压盖限位饰件已收掉。

侧弧形护板按同一右侧基准反射，左右弧口和端部朝向对应。侧阀、冷却匣、快门铰座和后柱支撑同步使用真实 X 镜像。

左右装配保持对称。前分发口与后压力柱承担不同功能，前后外形按工作方向区分。

## 动作与阶段

模型共 42 件、21 个关节。 关节坐标、父子关系、动画输入和原有工作行程保持原值。

召唤沿用实际 1.1 秒预警与一次释放。上下快门、供压阀、后压柱和注入器保持原行程；低位冲杆负责接触攻击。

主轮使用 `refined/drive-wheel`，64 段接触带保留现有直径、轴距、轴向、原点和滚动计算。轮胎采用原有同轴安装，左右承座及上层构件使用源顶点的真实 X 镜像。

## 素材与审查

部件继续引用 `models.json` 中已登记的许可源。承重面与护板采用 `corridor_wall`；实际导筒、门架、机匣和凹面装置保留各自完整源结构。原始 Kenney CC0 网格与许可证保留在 `development/assets/model_sources/kenney/`。

正前方检查上下快门和低位接触板的分层；左右侧面检查弧片反射方向、供压管与冷却匣；后侧检查压柱鞍座。

主进程统一编译并检查实际 PBR 画面，重点覆盖静止前后视、移动中的能力准备、释放与死亡姿态。
