# 记忆重铸机制作说明

四轮移动锻炉以六边门架、中央压头和前双钳形成轮廓。

## 装配与左右对称

单层折边底盘托住锻炉，原先藏在底盘中的成对传动小匣已收掉。修复臂使用连续承力壳，双钳采用有厚度的弧形接触面。侧臂、冷却匣和后辅助臂使用与转轴一致的完整轴承。

双钳、侧投射臂、冷却匣和第三阶段后投射臂全部使用真实 X 镜像。折臂源朝向与世界铰轴通过原矩阵组合，左右轴承原点与正负轴向对应。

静态结构左右对称。死亡时的异步落稳保持原动作。

## 动作与阶段

三个阶段分别为 38、42、50 件，共用 18 个关节。 关节坐标、父子关系、动画输入和原有工作行程保持原值。

修复预警、压头下压、环向释放和双钳攻击保持原行程。真实修复仍按三个阶段恢复比例执行，移动中的能力继续驱动轮胎。

- phase1：热罩闭合，侧臂直立。
- phase2：热罩后翻 43°，侧臂外展 35°，冷却匣展开 16°。
- phase3：热罩后翻 76°，侧臂外展 55°，冷却匣展开 38°，后辅助臂后展 51°。

主轮使用 `refined/drive-wheel`，64 段接触带保留现有直径、轴距、轴向、原点和滚动计算。轮胎采用原有同轴安装，左右承座及上层构件使用源顶点的真实 X 镜像。

## 素材与审查

部件继续引用 `models.json` 中已登记的许可源。承重面与护板采用 `corridor_wall`；实际导筒、门架、机匣和凹面装置保留各自完整源结构。原始 Kenney CC0 网格与许可证保留在 `development/assets/model_sources/kenney/`。

前低视检查弧形双钳的内外朝向和压头工作口；左右侧面比较投射臂；第三阶段后侧检查热罩与后辅助臂的间隙。

主进程统一编译并检查实际 PBR 画面，重点覆盖静止前后视、移动中的能力准备、释放与死亡姿态。首领同时检查三个阶段的装置间隙。
