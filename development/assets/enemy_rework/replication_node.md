# 复制节点制作说明

本轮从 40 件收为 28 件。四个主轮的来源、尺寸、位置和旋转保持原值，全部扫描、送料、舱门和攻击关节保持原坐标。

一片底盘和一张扫描床托住完整拱形扫描室，出舱侧只保留一个门框。左右各一条导轨承载滑架及相向扫描头，后方保留单个供能盒。删除重复后门框、外侧曲板、两根压扁横轴、变速箱、托盘下齿条、小机箱和铰轴饰环。

左右导轨、滑架、扫描头、夹爪、弧门和散热门使用 `handed(piece, side)`。两片弧门统一基准角度，通过左侧源网格 X 镜像形成配对曲面。送料托盘改为单片平直结构，床下保留导筒、活塞和短撞头。

原夹持、扫描、开门、送料和复位顺序沿用现有动作，复制结果与预算由战斗规则决定。主进程重点检查正面弧门接缝、两扫描头朝向、侧面单层导轨、开门末端与前门框的间隙，以及送料和攻击最大行程。实际材质与连续动作由主进程统一检查。

部件来自已登记的 Kenney CC0 网格与共用精细轮胎；原始素材和许可证保留在 `development/assets/model_sources/kenney/`。
